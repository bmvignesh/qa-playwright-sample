# QA Automation Sample Project (Playwright + TypeScript)

This repository demonstrates a simple QA automation framework using Playwright and TypeScript.

## Features
- End-to-end UI tests
- API validation
- Utilities for test data and helpers
- Continuous Integration with GitHub Actions

## Tech Stack
- **Playwright** for browser automation
- **TypeScript** for strongly typed test code
- **Node.js 24 (LTS)** in CI/CD pipeline
- **GitHub Actions** for automated test runs

## CI/CD
This project uses GitHub Actions to automatically:
- Install dependencies
- Run Playwright tests on every push or pull request
- Report build status via the badge above
